## Цель майлстоуна и критерий готовности

**Цель:** LLM превращает грязный текст состава в структуру по JSON-схеме.
Это ядро проекта — здесь появляется величина, которой нет в Open Food Facts:
**число разных форм сахара**.

**DoD из брифа:** LLM-корпус обработан, время и стоимость залогированы, замер
сделан заранее.

**Уточнённый DoD:**

- Замер на 20 продуктах выполнен для **каждой** из трёх версий промпта,
  экстраполяция записана в `DECISIONS.md` **до** полного прогона
- Корпус 3–5 тыс. продуктов обработан, результаты в `product_extraction`
- Повторный запуск пропускает уже обработанные, дублей извлечений нет
- Разные версии промпта дают **разные строки** для одного продукта —
  иначе сравнение версий в M3 невозможно
- `pytest` зелёный без докера и без Ollama, `pytest -m integration` — с БД

**Чего здесь НЕТ:** оценки качества. Без gold-набора судить о качестве нельзя,
а размечает его человек — это работа M3 (правило 6 брифа).

## Контекст исследования

**Проверено на живой модели `qwen2.5:3b-instruct-q4_K_M` перед планированием.**
Это не предположения, а результаты запусков.

**Что работает:**

- Генерация по JSON-схеме через параметр `format` — валидный JSON во всех
  попытках, схема с `enum` и nullable-полем принимается
- Скорость **2,5–10,5 с на продукт**, вход 208–232 токена, выход 133–360.
  На 3000 продуктов это ориентировочно 2–9 часов — вилка слишком широкая,
  чтобы планировать по ней, поэтому замер на корпусе обязателен

**Что сломано и определяет план:**

1. **Ключевая фича проваливается на наивном промпте.** Состав
   «Sugar, … Glucose-Fructose Syrup, Molasses» дал **0 форм сахара**.
2. **Русский промпт заставляет модель переводить канонические имена.**
   Их предстоит сопоставлять с таксономией OFF (`en:sugar`), поэтому промпт
   и требование к именам — на английском.
3. **HTML-разметка приходит прямо в составе:**
   `Hergestellt aus pasteurisierter <span class="allergen">Milch</span>`.
   Без очистки аллерген возвращается вместе с тегом. Предобработка обязательна.
4. **Главный конфликт, зафиксированный измерением:** подробные правила
   классификации ломают извлечение, короткий промпт ломает классификацию.
   - подробный промпт → 0 форм сахара на вложенных скобках;
   - короткий промпт → **все три формы сахара найдены**, скобки развёрнуты
     (13 ингредиентов из 12), но почти всё классифицировано как `flavouring`.

   Какая версия победит — решают метрики M3, а не мнение. Поэтому три версии
   промпта пишутся сразу, а не по одной.

**Данные корпуса M1** (фактические): 147 873 продукта, из них **89 120
с `unknown_ingredients_n > 0`** — кандидаты в LLM-корпус по ADR-006.
Языки перекошены: fr 151k, en 124k, de 59k, pl 5,7k, **ru 2,3k** — без
стратификации русских составов в выборку почти не попадёт.

## Границы майлстоуна

**Не входит в M2:**

- **Оценка качества и gold-набор** — это M3. Здесь меряются скорость, полнота
  и доля отказов, но не F1: без эталона он не считается
- Сравнение с облачной моделью и с парсером OFF — M3
- Обучение моделей на извлечённых данных — M4
- Эмбеддинги и поиск — M5

## Риски

| Риск | Признак | Что делать |
|---|---|---|
| Ни одна версия промпта не находит формы сахара надёжно | замер показывает near-ноль на составах с сиропами | это и есть результат: фиксируем и переносим решение в M3, где сравнение с облачной моделью покажет, предел это модели или промпта |
| Полный прогон дольше приемлемого | экстраполяция замера превышает порог | сузить корпус до 3 тыс. либо взять один промпт вместо трёх; решение по замеру, а не после суток ожидания |
| Русских и польских составов в выборке почти нет | стратификация не выполнила квоту | WARN в отборе; при недоборе честно указать в M3, что выводы по этим языкам слабые |
| Модель молча обрезает длинный состав | ответ выглядит валидным, но неполон | предобработка помечает составы длиннее `num_ctx` и не отправляет их |
| Одновременная загрузка модели и `bge-m3` не влезает в 6 ГБ | Ollama выгружает модель между вызовами, скорость падает | `keep_alive` из настроек, модели грузятся последовательно |
| Невалидный ответ ретраится бесконечно | прогон стоит на месте | ретрай только на `LLMUnavailableError`; `ExtractionError` не ретраится |
| Разные версии промпта перетирают друг друга | в БД одна строка на продукт | уникальность по `(code, model_name, prompt_version)` — задача 5 |
| Словарь алиасов растёт руками и отстаёт | доля неизвестных имён высокая | `extract dict unknown --top 50` показывает, куда пополнять по данным |
